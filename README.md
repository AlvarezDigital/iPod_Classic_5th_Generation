# iPod_Classic_5th_Generation
This single-file HTML application is an offline local music player styled as a white iPod Classic 5th Generation, built with HTML5, CSS (including Tailwind CSS via CDN), and vanilla JavaScript.
Key FeaturesAuthentic 5th Gen Hardware & LCD Styling: Features a metallic chrome outer rim, glossy white polycarbonate body, acrylic highlight reflection, 4:3 color LCD screen with a status bar and battery indicator, a tactile gray Click Wheel with quadrant buttons and center select button, and synthesized piezo click sound effects via the Web Audio API.   Cumulative Local Library & Drag-and-Drop: Lets users add music folders, individual or multiple audio files (.mp3, .m4a, .flac, .wav, .ogg, .aac, .opus), and cover images (.jpg, .jpeg, .png, .webp) via file pickers or drag-and-drop (including nested directory traversal), deduplicating files and accumulating tracks across sessions without wiping existing selections.   Metadata & Album Art Extraction: Parses ID3v2 tags (TIT2, TPE1, TALB, TRCK, and APIC artwork), FLAC Vorbis comments and PICTURE blocks, and MP4/M4A moov/iTunes metadata atoms (©nam, ©ART, ©alb, trkn, covr), falling back to folder/filename parsing, folder cover images, or a generated musical-note canvas placeholder.   Classic Navigation, Cover Flow & Now Playing: Organizes libraries into Music, Cover Flow (3D-styled horizontal album cover browsing), Albums, Artists, Songs, Settings (Clicker, Backlight, Contrast, Add Folder/Files, Clear Library), and Now Playing (split album art and track info, interactive seek scrubber, elapsed/remaining times, and volume bar overlay on wheel scroll).   Flexible Controls: Supports circular pointer/touch dragging on the Click Wheel, quadrant taps (MENU, Previous, Next, Play/Pause), center select clicks, mouse/trackpad wheel scrolling over the device, and keyboard shortcuts (ArrowUp/ArrowDown, ArrowLeft/ArrowRight, Enter, Space, Escape/Backspace).
